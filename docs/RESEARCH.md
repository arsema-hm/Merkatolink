# Research notes: how MerkatoLink models Merkato

Confidence is limited: available proposal research is desk research, partly secondary and some items explicitly described as older or low-confidence. It is not fieldwork and must be checked with traders before public claims.

| Model element  | Working model                                                                                             | Confidence / validation                                                                                    |
| -------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Terras         | Directory groups similar traders/products into sections such as Shema, Kimem, Somali, Termus and Minalesh | Names and grouping drawn from cited secondary sources in proposal; verify current boundaries/names locally |
| Delala         | Optional broker introduces buyer and trader; order earns a configurable commission                        | Proposal synthesis from market/broker research; commission norms must be interviewed                       |
| Credit         | Wholesaler records due date, partial payments and aging                                                   | Proposal cites trader-credit studies; confirm terms and common enforcement                                 |
| Hamal          | Porter is a delivery mode, not a platform user                                                            | Proposal flags source as low confidence; verify how porter fees and handoff work                           |
| Shop location  | Terra + shop number + landmark; avoid assuming standardized street addresses                              | Based on an older estimate/article; verify current addressing                                              |
| Imports and FX | Imported goods' USD cost and exchange rate can change replacement cost and margin                         | Product requirement; actual individual cost bases must be entered by each trader                           |

Interview two or three traders before describing these flows as representative. Get consent before quoting them, and omit identifiable personal/business details unless explicitly approved.
